## 2. `.gitignore` coverage

```gitignore
*.bin
*.pt
*.safetensors

```

All current artifacts are excluded. `*.pkl` at repo root is not globally ignored, but `models/**/artifacts/` catches model pickles.

## 3. External pretrained dependencies

| Component | External dep | Shipped? | Acquisition |
|-----------|--------------|----------|-------------|
| Semantic retrieval | BGE / MiniLM (HF) | No | `RETRIEVAL_ALLOW_HF=1` + download at train time |
| Normalizer | ModernBERT / ClinicalBERT | No | `NORMALIZER_ALLOW_HF=1` |
| Unlimited-OCR | `baidu/Unlimited-OCR` | No | HTTP endpoint or `UNLIMITED_OCR_ALLOW_LOCAL_DOWNLOAD=1` |
| Image quality | MobileNetV3 / EfficientNet | No | torchvision pretrained in train script |
| Risk/forecast/health | XGBoost/LightGBM on synthetic | Artifacts only | `models/*/train.py` |

## 4. What to commit per model

| Always commit | Never commit |
|---------------|--------------|
| `train.py`, `evaluate.py`, `infer.py` | `artifacts/*.pkl`, `*.npy`, FAISS indexes |
| `config.yaml`, `config_loader.py` | Hugging Face cache |
| `model_card.md`, `README.md` | Multi-GB VLM weights |
| `requirements.txt` | W&B / MLflow run blobs |
| Feature flag wiring in registry | |

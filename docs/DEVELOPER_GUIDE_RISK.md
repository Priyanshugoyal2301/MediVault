# Developer Guide — Disease Risk (Phase 4)

1. Keep `USE_RISK_MODEL=0` for demos.  
2. Train: `python models/risk_prediction/train.py`  
3. Smoke: enable flag, `get_risk_predictor().predict([...])`  
4. Never display results without disclaimers.  
5. Tests: `python -m pytest tests/phase4 -q`  
6. Do not start Phase 5 until validation accepted.

# Knowledge Base — `data/knowledge-base`

## Purpose

Curated medical source documents used by the RAG Q&A pipeline (Feature 3).

## Populated at

Feature 3 build.

## Format

- Plain-text or PDF documents, chunked and embedded at ingestion time.
- Each document must have a citable source (author, publication, URL, or standard reference).

## Sourcing criteria

- Authoritative sources only: published clinical guidelines, national health bodies (e.g. ICMR, NHS, NIH), peer-reviewed meta-analyses.
- No unverified third-party content.
- Licensing: must permit use in a software product — document the licence for each source here before ingestion.
